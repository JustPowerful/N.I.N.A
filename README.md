## N.I.N.A AI Agent

N.I.N.A. — Nearly Intelligent. Nicely Automated. is an open-source AI Agent with experimental tools integrated to it.

It's made to be a personal assistant that can help you with various tasks, such as answering questions, having a knowledge base, sending emails, scheduling your calendar, and more.

The current version of N.I.N.A is a prototype and is still in development. It is not yet ready for production use, but you can try it out and provide feedback.

## Core components

- [Agent Core](/nina-core) - The main engine of N.I.N.A, responsible for processing user input and generating responses.
- [Web Interface](/nina-web) - A web-based interface for interacting with the N.I.N.A AI Agent.
- [Telegram Bot](/nina-telegram) - The Telegram bot that allows users to interact with the N.I.N.A AI Agent.

## Note

This project is still in development, and the codebase may change significantly in the future to include more features, improvements and deployment options. Please feel free to contribute, report issues, or suggest new features.
