This is an important folder that contains the credentials for the Google API.
It's crucial to keep this folder secure and not expose it publicly, as it contains sensitive information that can be used to access your Google account and services.

Needed file to generate the credentials token.json is client_secret.json.
You can obtain the client_secret.json file by creating a project in the Google Cloud Console, enabling the Gmail API, and creating OAuth 2.0 credentials.

IMPORTANT: Enable the Gmail API in your Google Cloud Project and download the client_secret.json file. Place it in the credentials folder.
